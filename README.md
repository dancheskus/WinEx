# WinEx

Проводник в стиле Windows Explorer для macOS 26+, который может подменять Finder.

## Установка

1. Скачайте `WinEx-<версия>.zip` со страницы [Releases](https://github.com/dancheskus/WinEx/releases),
   распакуйте и перенесите `WinEx.app` в «Программы».
2. Первый запуск: WinEx не подписан платным сертификатом Apple, поэтому macOS не откроет его
   двойным щелчком. Откройте «Системные настройки ▸ Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть» у WinEx (или в Терминале: `xattr -dr com.apple.quarantine /Applications/WinEx.app`).
   Это нужно один раз.
3. Включите WinEx в «Системные настройки ▸ Конфиденциальность и безопасность ▸ Полный доступ к диску» —
   тогда не будет отдельных вопросов про Рабочий стол, Документы, Загрузки, сетевые диски, и
   откроется Корзина.

Дальше WinEx обновляется сам: раз в сутки проверяет Releases и предлагает «Обновить и перезапустить»
(«Настройки» или меню в строке меню ▸ «Проверить обновления…»). Обновление скачивает сам WinEx, поэтому
macOS больше не спрашивает про запуск, а все разрешения сохраняются: каждая версия подписана одним и тем
же сертификатом, и WinEx ставит обновление, только если подпись совпадает.

## Выпуск версии

```sh
git tag v1.2.0 && git push origin v1.2.0
```

GitHub Action `.github/workflows/release.yml` собирает WinEx с этой версией, подписывает сертификатом
«WinEx Signing» (секреты `SIGNING_P12_BASE64` и `SIGNING_P12_PASSWORD`) и публикует
`WinEx-1.2.0.zip` в Releases. Локальные сборки помечены как «своя сборка» и сами не обновляются.

## Сборка и запуск

```sh
./build.sh          # собирает build/WinEx.app (release)
open build/WinEx.app
```

Нужны только Command Line Tools (Swift 6.2+), Xcode не обязателен.

### Подпись и разрешения

Один раз выполните `scripts/setup-signing.sh`: он создаёт самоподписанный сертификат «WinEx Signing»
(копия и пароль — в `~/.winex-signing`, сохраните их в надёжном месте), кладёт его в связку ключей
«вход», и `build.sh` подписывает им каждую сборку. На другом Mac: `scripts/setup-signing.sh файл.p12`.
Тем же сертификатом подписываются релизы в GitHub Actions.
Тогда macOS считает новые сборки тем же приложением, и разрешения («Полный доступ к диску»,
Рабочий стол, Документы, Загрузки, сетевые тома) выдаются один раз, а не после каждой пересборки.
Без сертификата сборка подписывается ad-hoc, и разрешения сбрасываются при каждой сборке.

## Проверка

```sh
swift test                         # модульные тесты логики (имена, теги, .DS_Store, отмена, горячие клавиши)
scripts/run-scenario.sh undo       # сценарий в самом приложении: undo, newfolder, slowclick, perf,
                                   # desktop (картинка в build/scenario-desktop/), hittest, placement, placement2, desktopreset, monitorgone, fileops, search, filecommands, drives, trashaccess, update;
                                   # mousedrag — с настоящей мышью, вместе со scripts/mouse-drag-check.swift
```

Сценарии есть только в отладочной сборке: приложение управляет собой изнутри (без настоящей мыши и
клавиатуры), пишет журнал и завершается само. Настройки у сценария свои, отдельные — ваши настройки
WinEx и режим «вместо Finder» тест не трогает.

## Что есть

- Вкладки: перетаскиваются мышкой, отрываются в новое окно (утащить вверх/вниз от полосы вкладок),
  вкладку можно бросить на полосу вкладок другого окна. Средняя кнопка мыши закрывает вкладку.
- Назад / Вперёд / Вверх (⌘[ ⌘] ⌘↑). Клавиши как в Finder: Enter — переименовать, ⌘↓ / ⌘O — открыть.
  Настройка «Клавиши как в Windows» (по умолчанию выключена): Enter — открыть, F2 — переименовать,
  Backspace — вверх. Стрелки и ⇧+стрелки работают в таблице, в сетке и на рабочем столе.
- Редактируемая строка пути (⌘L): можно скопировать, вставить путь и нажать Enter. Понимает `~` и `file://`.
- Боковая панель: «Быстрый доступ»; «Места» — iCloud Drive, диски и сетевые папки (⏏ извлечь),
  AirDrop (системное окно), «Сеть» (серверы из Bonjour, подключение с системным входом), «Корзина»
  («Вернуть», «Удалить навсегда», «Очистить Корзину»; нужен «Полный доступ к диску»); «Теги».
  «Подключиться к серверу…» — ⌘K, «Поделиться…» (AirDrop и др.) — в контекстном меню.
- Виды: огромные / крупные / обычные / мелкие значки, список, таблица, плитка
  (кнопка «Вид» в панели, ⌘1…⌘7, ⌘+колёсико или щипок — как Ctrl+колёсико в Windows).
  Крупные значки показывают миниатюры картинок и документов.
  Вид запоминается для каждой папки отдельно; «Вид ▸ Применить ко всем папкам» делает текущий вид
  видом по умолчанию и сбрасывает запомненные.
- Пробел — быстрый просмотр (Quick Look) выделенных файлов, в окнах и на рабочем столе;
  стрелки листают файлы, пока просмотр открыт.
- Выделение как в Windows во всех видах: ⇧-клик — диапазон от «якоря», ⌘-клик — добавить/убрать,
  ⇧⌘-клик — добавить диапазон, ⇧+стрелки, Home/End, рамка по пустому месту, набор имени с клавиатуры.
- Файлы: сортировка, поиск по имени, контекстное меню, переименование (F2), новая папка (⇧⌘N),
  копирование/вырезание/вставка файлов (⌘C / ⌘X / ⌘V; вырезанные файлы бледнеют, пока их не вставят
  или пока в буфер не попадёт что-то другое, вставка перемещает), в корзину (⌘⌫), перетаскивание файлов в другие приложения.
- Значок в Dock (жёлтая папка; перерисовать — `swift Resources/make-icon.swift`). Клик по нему выводит
  окна, разворачивает свёрнутое или открывает новое; правый клик — список открытых папок (вкладки
  сгруппированы по окнам) и «Новое окно». Значок в строке меню остаётся: «Выйти» там возвращает Finder.

- Отменить / Повторить (⌘Z / ⇧⌘Z, на русской раскладке — ⌘Я): переименование, перемещение в Корзину,
  перемещение, копирование, создание папок и файлов, изменение тегов — одна история на все окна
  и рабочий стол; пока идёт ввод текста (имя, строка пути), ⌘Z отменяет ввод.
- «Свойства» (⌘I или ⌥↩, как Alt+Enter) для файла, папки или группы: тип, программа по умолчанию
  (можно сменить), расположение, размер и содержимое папок (считается в фоне), даты, теги, атрибуты
  «Только чтение» и «Скрытый».
- Теги Finder: строка цветных кружков в контекстном меню, цветные точки у имён, столбец «Теги», «Теги ▸»,
  редактирование в «Свойствах»; раздел «Теги» в боковой панели показывает все файлы с тегом (Spotlight).
- «Настроить папку…» как в macOS 26: цвет (тег), символ или эмодзи на папке — в формате Finder
  (атрибут `com.apple.icon.folder#S`), так что Finder видит те же настройки.
- Контекстное меню как в Windows: «Открыть с помощью ▸» (программы из системы + «Выбрать другую…»),
  «Создать ▸» папку и файлы — txt, RTF, Markdown, Word, Excel, PowerPoint (только если есть программа,
  которая их открывает), «Сортировка ▸», «Вид ▸». Файлы и папки можно перетаскивать между окнами,
  на папки и на рабочий стол (⌥ — копировать).
- Окно запоминает место, размер и монитор: новое окно, открытое когда других нет, появляется там,
  где было окно, которое последним двигали, меняли по размеру или закрыли (при выходе — переднее; если монитор отключён — на главном). Следующие окна
  открываются лесенкой от переднего окна, того же размера.
- «Этот Mac» (первым в «Местах»): все диски с полосой заполнения (красная, когда занято > 90%) и
  «X свободно из Y», отдельно — сетевые; двойной щелчок открывает, «Извлечь» в меню.
- В строке состояния — размер выделенного: файлы сразу, папки досчитываются в фоне (с низким
  приоритетом, после паузы в выделении, отменяется при смене выделения).
- Пустой список объясняет себя: «Эта папка пуста», «Ничего не найдено», «Нет доступа к Корзине»
  (с кнопкой настроек «Полного доступа к диску»; после выдачи доступа Корзина перечитывается сама,
  когда вы возвращаетесь в WinEx).
- Настройка «Новые окна открываются в»: домашняя папка, рабочий стол, загрузки, документы, «Этот Mac»
  или любая папка — для нового окна, значка в Dock и глобального сочетания.
- Команды Finder (контекстное меню и «Файл»): «Дублировать» (⌘D), «Сжать» (один объект → «имя.zip»,
  несколько → «Архив.zip»), «Распаковать» (и двойной щелчок по .zip — распаковка рядом, без Archive
  Utility), «Создать псевдоним» (⌃⌘A), «Показать оригинал», «Показать содержимое пакета». Псевдоним
  папки открывается в WinEx. Всё отменяется ⌘Z.
- Глобальное сочетание, как Win+E: открывает окно WinEx из любой программы (по умолчанию ⌥⌘E,
  в настройках — другое или выключить). Регистрируется в системе, без мониторинга клавиатуры.
- Всегда: ⌃Tab / ⌃⇧Tab и ⌃1…9 — вкладки; перетаскивание с ⌘ — переместить (даже на другой диск),
  с ⌥ — копировать, с ⌘⌥ — создать псевдоним. С «Клавишами как в Windows» ещё F3, F4 / ⌥D, F5, F11,
  Delete, ⇧Delete, ⌥← ⌥→ ⌥↑, ⇧F10 (стрелки и Delete не мешают тексту в полях ввода).
- Поиск (⌘F или поле в панели): ищет в текущей папке и вложенных (или на всём Mac — меню поля),
  в именах (все слова, без учёта регистра и «ё/е») и в содержимом файлов. Результаты — как папка:
  «Назад» возвращает, столбец «Папка», «Показать в папке», обновляются сами. Недавние запросы — в меню поля.
  Работает на Spotlight: своего индекса нет, фоновых сканирований нет — пока не ищете, WinEx не тратит
  процессор. Запрос стартует через 0,35 с после ввода, показываются до 2000 самых подходящих,
  живые обновления не чаще двух раз в секунду, запрос останавливается, как только результаты скрыты.
  Папки, которых нет в индексе Spotlight (сетевые, часть внешних дисков), просматриваются по именам
  разово, с низким приоритетом и ограничением (⌘R — заново).
- Копирование, перемещение, Корзина и удаление — как в Windows: если работа идёт дольше полсекунды,
  появляется окно хода с процентами, паузой, отменой, графиком скорости, оставшимся временем и
  объёмом («Меньше / Больше подробностей»). Если имена совпадают — окно «Замена или пропуск файлов»:
  заменить (старые файлы уходят в Корзину), пропустить или решить для каждого файла (заменить /
  пропустить / оставить оба). Копирование на APFS — клонами (мгновенно, без лишнего места).
- Папки читаются в фоне: окно не замирает даже на десятках тысяч файлов, а поток изменений
  (копирование тысяч файлов) обновляет список несколько раз, а не на каждый файл.

## Рабочий стол WinEx

- Клик по пустому месту убирает окна, как «Нажатие на обои» в «Рабочий стол и Dock» (учитывает эту настройку
  и «Показывать объекты на рабочем столе / в Stage Manager»).
- Миниатюры файлов (со скруглёнными углами), цветные теги, диски по настройкам Finder
  («Показывать на рабочем столе»), «Извлечь».
- Подписи как в Finder: до двух строк, длинное имя сокращается в середине второй строки, так что
  расширение видно («Ответы для / сиротс…2.0.docx»).
- Несколько мониторов: на каждом свой рабочий стол со своими значками, значки перетаскиваются между
  ними. Если монитор отключён (ноутбук без мониторов), его значки временно показываются на основном
  и возвращаются, когда монитор снова подключён.
- При первом запуске берёт раскладку значков из Finder (`~/Desktop/.DS_Store`, записи `dilc`:
  байты 0…3 — номер монитора), потом хранит свою. Значки обходят виджеты рабочего стола, как в Finder.
- Значки перетаскиваются мышью, выделяются рамкой, переименовываются (F2).
- Меню: «Вид ▸» крупные/обычные/мелкие значки, «Упорядочить значки автоматически»,
  «Выровнять значки по сетке», «Отображать значки рабочего стола»; «Сортировка ▸» имя/размер/тип/дата;
  «Создать ▸» — новый файл появляется там, где открыли меню.

## Настройки

- «Открывать WinEx при входе в систему» — объект входа (Системные настройки ▸ Основные ▸ Объекты входа);
  при входе WinEx запускается без окна.
- «Сбросить рабочий стол как в Finder…» (с подтверждением) — забывает расстановку WinEx и берёт
  у Finder места значков (`~/Desktop/.DS_Store`), размер значков и сортировку (`DesktopViewSettings`).

## Режим «вместо Finder» (Настройки)

При включении:
- `defaults write -g NSFileViewer dev.winex.WinEx` — «Показать в Finder» в других приложениях открывает WinEx;
- `defaults write com.apple.finder CreateDesktop -bool false` + перезапуск Finder — рабочий стол рисует WinEx.

Сделать WinEx программой по умолчанию для папок нельзя: на macOS 26+ LaunchServices отвечает
`paramErr (-50)` на смену обработчика `public.folder`. Поэтому папки, которые другие приложения
открывают напрямую (`open ~/Documents`), по-прежнему открываются в Finder.

При выходе из WinEx всё откатывается. Если WinEx упал или его убили, это делает «сторож» —
отдельный процесс, который ждёт исчезновения WinEx и возвращает Finder рабочий стол.
Если рабочий стол всё же пропал:

```sh
defaults delete com.apple.finder CreateDesktop; defaults delete -g NSFileViewer; killall Finder
```
